# 原项目功能与 Android 移植清单

更新日期：2026-10-21。基准提交：`850a667`。

Android 当前已完成加载基础和游戏内卡牌图鉴。对局物品同时展示多种附魔效果的
悬浮信息功能尚未完成；它仍是优先适配项。

本文整理功能覆盖范围；真机环境、操作与验证证据以
[真机验证记录](device-validation.md) 为准。下表中的“未移植”仅表示 Android 状态。

## 原项目主要功能与 Android 状态

| 功能 | 原项目提供的能力 | Android 当前状态 |
|---|---|---|
| 卡牌图鉴 | 查阅物品、技能，搜索及多维度筛选 | 主要功能已实现，详情见下表 |
| 附魔预览 | 在物品提示中同时展示多种附魔效果 | 原型停用：启用新增钩子会闪退，仍需修复 |
| 升级预览 | 比较物品升级后的效果 | 图鉴内品质切换已实现；对局提示增强未移植 |
| 事件及奖励预览 | 事件、遭遇、任务、英雄升级奖励提示 | 未移植 |
| 对局历史 | 保存、筛选和查看对局及双方阵容 | 未移植 |
| 战斗回放与幽灵对战 | 重播战斗、查看或挑战保存的阵容 | 未移植 |
| 视频录制与截图 | 录制回放、结算截图 | 未移植 |
| 战斗状态栏 | 战斗时间、暂停和速度控制 | 未移植 |
| 战后影响分析 | 查看物品的战斗贡献 | 未移植 |
| 构筑推荐 | 展示推荐构筑，与当前阵容等对照 | 未移植 |
| BazaarDB 上传 | 后台上传对局及阵容数据、账号绑定 | 未移植 |
| 中文术语及名称增强 | 大陆／台湾／香港术语、双语物品名、外观名称 | 图鉴中文已接入；术语切换及名称增强未移植 |
| 语音字幕 | 游戏语音字幕展示 | 未移植 |
| 传奇名次显示 | 隐藏名次、替代显示、名次与分数双显 | 未移植 |
| 匿名模式 | 隐藏或替换玩家名称 | 按用户要求暂缓 |
| 主播／直播模式 | 为 OBS 等提供对局信息叠层 | 按用户要求暂缓 |
| 模组设置及快捷键 | 功能开关、模式切换、按键绑定 | 尚未接入 Android 设置界面 |
| 安装器与自动更新 | 安装、修复、卸载、历史管理和更新 | 尚无 Android 安装器；当前使用 FusionCore 加载 |

## Android 已实现清单

| 模块 | 已实现并验证的内容 |
|---|---|
| 加载基础 | IL2CPP 插件加载、Unity 帧回调、真机运行 |
| 卡牌目录 | 读取游戏静态数据；当前显示 1,243 个物品、517 个技能 |
| 分类筛选 | 物品／技能、英雄、起始品质、体型 |
| 搜索浏览 | 名称和描述搜索、清空、分页、重置筛选；英文查询命中中文卡名 |
| 卡面展示 | 小／中／大型物品和技能的游戏原生卡面 |
| 效果描述 | 原生效果文字、数值与属性图标 |
| 品质预览 | 图鉴内切换青铜、白银、黄金、钻石，并更新数值 |
| 附魔变体 | 图鉴内切换附魔，更新卡面及效果，支持恢复“无” |
| 界面生命周期 | 关闭重开、连续换卡、切到系统桌面后恢复等正常路径 |

## 未完成与验证边界

- 原生长按详情与附魔下拉目前正常：已在皮格健身房上验证“炽焰”卡面及灼烧加成 24。
  这是游戏原有能力恢复可用，不能算多附魔悬浮功能完成。
- `android-mod/Plugin.Load` 暂不注册 `AndroidEnchantTooltip` 或调用其安装入口。
  `AndroidEnchantPreview` 与 `AndroidEnchantTooltip` 的源码保留，但没有启用。
- 图鉴的来源／商人筛选、按当前天数过滤尚未接入 Android 界面。
- 长描述滚动已实现，但滚动到末尾的专项触屏验证尚未完成。
- 异常注入和生成途中销毁 Controller 的场景仅完成源码复核，尚未通过真机故障注入验证。
- 当前验证仅覆盖真机记录中的设备与游戏版本，不能推断其他设备或版本同样可用。
