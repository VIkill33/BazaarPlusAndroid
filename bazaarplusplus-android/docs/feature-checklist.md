# 原项目功能与 Android 移植清单

更新日期：2026-10-22。各项状态以本文件所处提交为准。

Android 当前已完成加载基础和游戏内卡牌图鉴。对局物品同时展示多种附魔效果的
悬浮信息已在标准和高级输入模式显示多种附魔效果，高级模式的多档升级描述也已显示；
附魔与升级的具体数值仍需逐项对照游戏结果。

本文整理功能覆盖范围；真机环境、操作与验证证据以
[真机验证记录](device-validation.md) 为准。下表中的“未移植”仅表示 Android 状态。

## 已写入当前代码，待真机验证

以下功能已经接入 Android 插件，但离线编译或单元测试不能证明游戏内可用，因此不计入上面的已完成清单。

| 功能 | 当前代码已实现的范围 | 尚需验证或补齐 |
|---|---|---|
| 多附魔悬浮预览 | `Plugin.Load` 注册 `AndroidTooltipObserver`；观察原生物品提示并用 `AndroidEnchantPreview` 同时渲染可选附魔；物品附魔或属性变化时重新渲染；左侧可预先切换长按默认展示内容 | 标准与高级模式的果篮长按、滚动和松开关闭已由用户确认；附魔实际数值及其他物品仍需扩大验证 |
| 对局升级预览 | 物品提示投影所有可用的更高品质属性、冷却与光环倍率，使用独立卡牌实例渲染原生描述；左侧可在长按前选择直接展示升级页 | 高级模式 4 档描述和滚动已由用户确认；标准模式、光环数值与实际升级结果仍待比对；日志校验原物品品质和属性未变化 |
| 事件及奖励预览 | 事件卡列出可解析的结果、后续遭遇及可计算的概率；英雄等级提示列出生命、格数与可能出现的奖励选项，不把候选权重显示成获得概率；物品提示增加原生文字渲染的「任务奖励」页签 | 真机展示与实际结果比对；动态卡池条件、其他奖励类型和完整事件链仍需补齐 |
| 构筑推荐 | 异步获取并缓存十胜构筑数据；选择场上、仓库、商店候选卡并分页；按候选匹配及当前三区物品排序；使用游戏原生卡牌渲染器展示单条十格阵容，可切换前三条并逐件标出场上／仓库／商店／未拥有 | 新版面板、场上候选反选／复选及切换到空商店已在真机验证，无数据时收起空阵容区；当前英雄无样本，新卡面阵容、匹配排序、非空仓库／商店、断网仍待真机验证 |
| 野怪长按浮层 | 使用游戏原生卡牌渲染器绘制野怪全部物品图像，保留重复物品；默认仅显示卡图，单卡宽严格按屏幕宽度的 1/26 等比缩放；松开长按后保留浮层，点击卡图再显示物品信息，点击空白或 × 关闭 | 蕉宝、獠牙英格狼、毒蛇各 4 张物品卡已真机显示；2460 像素屏宽记录卡宽 94.6 像素，蕉宝医疗包点击详情及空白关闭已验证；多行阵容及标准输入模式仍待验证 |

## 未完成与验证边界

- 原生长按详情与附魔下拉目前正常：已在皮格健身房上验证“炽焰”卡面及灼烧加成 24。
  这是游戏原有能力恢复可用，不能算多附魔悬浮功能完成。
- `android-mod/Plugin.Load` 已注册 `AndroidTooltipObserver`。旧版
  `AndroidEnchantTooltip` 及其专用运行时路径适配已经移除；双输入模式下的附魔浮层交互已在果篮验证，其他物品和附魔数值仍待对照。
- 升级页已在高级输入模式真机显示 4 档更高品质内容；构筑推荐面板及场上候选也已显示。
  任务奖励和事件结果仍没有真机通过证据，也没有确认事件奖励覆盖完整。
- 图鉴的来源／商人筛选、按当前天数过滤尚未接入 Android 界面。
- 长描述滚动已实现，但滚动到末尾的专项触屏验证尚未完成。
- 异常注入和生成途中销毁 Controller 的场景仅完成源码复核，尚未通过真机故障注入验证。
- 当前验证仅覆盖真机记录中的设备与游戏版本，不能推断其他设备或版本同样可用。
