# 原项目功能与 Android 移植清单

更新日期：2026-10-24。各项状态以本文件所处提交为准。

当前品质规则：对局升级预览候选最高为钻石，排除传奇升级目标；左侧「长按预览」按「附魔 → 升级 → 无」循环并保存，兼容原有附魔／升级偏好。「无」保留原生物品详情，关闭物品附加预览。品质上限修正已通过离线回归和插件编译，实际升级数值仍待对照；下文历史“四档”和“滚动至传奇档”仅为旧版展示路径记录，不代表品质规则正确。

本次设置更新：游戏原生设置的语言选项下方加入「BPP：长按预览」（附魔／升级／无）和「BPP：预览面板位置」（默认位置／靠屏幕左侧边缘）。长按偏好与左侧快捷按钮共用，位置设置与启动器共用持久化文件，后续预览渲染使用新位置。用户已确认两项设置真机验证通过；本次未重新执行设备操作，详见[真机验证记录](device-validation.md)。

最新预览增强：商店已显示当前天数品质概率，事件已增加原生奖励数值、条件说明、卡池限制和后续遭遇。米透、丛林遗迹、挖掘行动在标准与高级模式的展示及关闭已真机验证；未选择事件或推进对局，结束时恢复高级模式。其他天数、固定高品质商店、复杂条件和实际领取后的对照仍待验证，详见[真机验证记录](device-validation.md)。

增强前的首轮验证：高级模式下茸茸小怪兽七个结果及条件标记可见；吉娜、安保中心仍只显示动态卡池占位，具体候选未展开。标准模式未通过。测试中误选事件并退出至升级阶段，经过与证据见[真机验证记录](device-validation.md)的专项检查节；不视为完整功能验收。

Android 当前已完成加载基础和游戏内卡牌图鉴。对局物品同时展示多种附魔效果的
悬浮信息已在标准和高级输入模式显示多种附魔效果，两种模式的多档升级描述也已显示；
附魔与升级的具体数值仍需逐项对照游戏结果。

本文整理功能覆盖范围；真机环境、操作与验证证据以
[真机验证记录](device-validation.md) 为准。下表中的“未移植”仅表示 Android 状态。
