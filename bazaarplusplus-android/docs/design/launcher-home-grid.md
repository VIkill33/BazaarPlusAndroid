# 启动器首页：第二版按钮布局

2026-10-26 用户选定本图，并要求落实到现有原生 Android 启动器。

![第二版](launcher-home-grid.png)

仅修改按钮布局、图标与首页专用样式，保留原集市背景、品牌、启动前状态、署名、版本和全部入口行为。

- 「启动游戏」为全宽琥珀主按钮。
- 六个次要入口为两行三列：对局历史／设置／帮助，重新检查／打赏作者／Github。
- 「更多：修复与许可」为底部全宽次要按钮。
- 网格使用 64dp 最小高度、24dp 图标及 14sp 标签，原生滚动与系统字体适配继续生效；其他页面沿用原样式。

原型由内置 Image Gen 生成，输入为项目现有集市背景与暮紫琥珀参考图。原生实现复用背景及既有刷新、帮助图标，新增图标来源与许可见 `assets/launcher-icons/SOURCE.md`；不将原型整体作为界面图片。
