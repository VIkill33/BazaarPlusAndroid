## 第 0 步：先让它编译通过

按 `AGENTS.md` 的离线检查命令构建插件（`build_probe.py ... --mod`）。预期最可能出问题的地方：

- [ ] `android-mod/AndroidFavoriteMarks.cs` 的 `Match`：`Data.CardAndSkillLookup` 与 `GetCardController(...)` **只有桌面版用法为依据**（见 `bazaarplusplus-mod/src/BazaarPlusPlus/Game/CombatReplay/CombatReplayRuntime.cs`），未对照手机版代理。若不存在或签名不同，在手机版 interop 中找等价的“卡牌 → `CardController`”入口；找不到时回退为 `Resources.FindObjectsOfTypeAll<CardController>()` 并按 `CurrentTooltipData` 的卡牌实例匹配。
- [ ] `android-mod/AndroidHoldPreviewVisuals.cs` 的 `CardBounds`：从 `TargetBounds` 提取出的静态方法，确认长按预览的聚焦挖洞行为没有变化。
- [ ] `android-mod/CustomBuilds/CustomBuildStore.cs`：`int?` 格位的可空警告（测试工程开了 `TreatWarningsAsErrors`）。
- [ ] `android-mod/AndroidBuildBoard.cs`：新增 `keepSlots` 参数；默认值下推荐构筑的排布必须与改动前一致。
- [ ] 插件要求零警告编译。

编译错误直接在本分支修复，每个修复单独提交，提交说明写清原因。

## 第 3 步：真机验证

每项都要截图并配合插件日志断言；截图人工复核须如实标注。标准与高级输入模式分别覆盖。

### A. 页面视觉（`33b6392`）

- [ ] 「我的构筑」标题金色加粗左对齐，旁边显示「共 N 套」。
- [ ] 无构筑时列表区居中显示引导，底部状态栏为空。
- [ ] 构筑行：名称金色加粗，「N 件 · X/10 格 · 时间」弱化；含失效物品时显示珊瑚色「N 件物品不可用」。
- [ ] 编辑页：已用格数为放大的金色数字，右侧十格容量条按已用格数点亮；物品清单为斑马行，占格数右对齐。
- [ ] 中文与英文下文字不重叠、不被截断，重点看：容量文字与容量条、行名称与右侧按钮。
- [ ] 启动器开启与关闭集市面板主题两种情况下配色都可读。

### B. 编辑与任意空格拖放（`f8bc4ff`）

预期行为：

- 物品落在其左边缘所在的格位，空位保留；拖动时目标格以金色半透明高亮，状态栏显示「松手放到第 N 格」。
- 落在已占格时相邻物品被推开；右侧放不下时整体向左挤。
- 从图鉴添加时放入第一个够大的空位；总空格够但无连续空位时自动收拢腾位。
- 旧存档没有格位字段，读取时按顺序左对齐。

检查项：

- [ ] 升级前先保留一份旧版 `BepInEx/config/BazaarPlusPlus.Android/custom-builds.json`；升级后旧构筑正常左对齐显示，文件未被破坏。
- [ ] 列表「编辑」进入后标题为「编辑构筑」，新建时为「新建构筑」。
- [ ] 把小型物品拖到右端空格，松手后留在原处并留出空位；高亮格与实际落点一致。
- [ ] 把物品拖到已占格上，相邻物品被推开，没有重叠，没有物品丢失。
- [ ] 大型物品拖到最右侧，被限制在第 8–10 格内。
- [ ] 拖出阵容区松手取消；拖入红色删除区松手删除；移出删除区再松手不删除。
- [ ] 保存后回到列表原滚动位置，该构筑的创建时间与列表位置不变，空位在列表行里同样显示。
- [ ] 编辑中点「返回」放弃修改，原构筑不变。
- [ ] 关闭重开游戏后格位仍然保留。
- [ ] 回归：构筑推荐页的推荐阵容排布、点击物品看详情与改动前一致。
- [ ] 日志：`android.custom_build.edit_started`、`android.custom_build.drop slot=...`、`android.custom_build.saved edited=True`。

已知限制（确认即可，不必修）：物品尺寸随游戏版本变大导致棋盘超过十格时，落点高亮会偏移；含失效物品的构筑须先把该物品拖去删除才能保存。

### C. 收藏提醒与卡牌角标（`a17201f`）

预期行为：

- 「我的构筑」每行有「开启提醒／提醒中」按钮，可同时开启多套；每套占一种颜色（六色，优先取未占用的，用完循环），行侧边条与按钮文字为同色。
- 构筑推荐页阵容上方「收藏并提醒」把当前推荐构筑存入「我的构筑」并开启提醒；物品与位置完全相同的构筑已存在时只开启提醒。
- 游戏当前可选卡牌属于任一提醒中的构筑时，卡牌左上角显示该构筑颜色的深色描边菱形；同属多套时并排，最多三枚。
- 打开构筑、图鉴、历史面板或长按预览时角标隐藏；角标不拦截触摸。

检查项：

- [ ] 开启两套以上提醒，颜色互不相同；关闭一套再开启另一套，释放的颜色被复用。
- [ ] 「收藏并提醒」后按钮变为「已收藏」，「我的构筑」出现该构筑且提醒已开；对同一构筑再点一次不产生重复。
- [ ] **商店**：含提醒构筑卡牌的商店里，对应卡牌左上角出现正确颜色的角标，其余卡牌没有。
- [ ] **野怪奖励**：战胜野怪后的奖励选择中角标出现。
- [ ] **事件给牌**：事件提供物品选择时角标出现。
- [ ] 后两项若不出现，查明该场景的卡牌是否进入 `Data.CurrentState.SelectionSet`；不进入则找到对应数据来源并补上，或如实记为不支持。
- [ ] 一张卡同属两套提醒构筑时并排显示两枚不同颜色的角标。
- [ ] 小、中、大型卡牌上角标的大小与位置都贴近左上角且不遮挡关键信息。
- [ ] 卡牌飞入、刷新商店、购买后，角标跟随正确，没有残留在空位或别的卡上。
- [ ] 打开插件面板、长按预览时角标消失，关闭后恢复。
- [ ] 游戏自带弹窗、提示框、设置界面出现时，角标是否盖在其上；若是，需要在这些界面出现时隐藏。
- [ ] 进入战斗、返回大厅、切换场景后没有残留角标。
- [ ] 点击带角标的卡牌，购买／选择的触摸不受影响（此项需要用户授权改变对局状态后才执行）。
- [ ] 关闭所有提醒后角标全部消失；删除提醒中的构筑后其角标消失。
- [ ] 日志：`android.favorite_marks.loaded builds=.. cards=..`、`android.favorite_marks.matched offered=.. marked=..`；不应出现 `android.favorite_marks.failed`，也不应逐帧刷日志。

排查提示：`loaded` 的 `cards` 为 0 说明没读到提醒构筑；`matched` 的 `offered` 大于 0 而 `marked` 为 0 说明模板匹配或卡牌对象查找失败；`marked` 大于 0 但屏幕上没有角标说明是定位或画布层级问题。
