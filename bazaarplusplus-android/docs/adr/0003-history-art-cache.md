# ADR-0003：启动器历史使用游戏导出的本机插画缓存

状态：采用；真机覆盖范围见设备验证记录。

启动器不装载 Unity，也不从网络查询卡牌图片。`AndroidHistoryArtwork` 在游戏主线程调用手机版原生资源入口，导出默认英雄头像、奖杯及历史快照涉及的模板插画。图片不包含账号、玩家名称、玩家头像或实际卡牌实例。

`HistoryReader.artwork` 使用宿主确定的账号／暂存会话范围，只投影 PvP 快照的模板 ID，以快照行号分页，不依赖旧版 Android 未必具备的 SQLite JSON 扩展。回填在游戏内历史关闭、非战斗时执行，使用现有读取桥；当前查询让位于用户浏览，取消后延迟重试。

图片目录由 `AndroidHistoryArtwork` 拥有，位于目标游戏的 `BepInEx/history-art/v2/`，子目录以当前游戏版本的 SHA-256 区分。`source.json` 标注来源游戏版本，`current.txt` 指向当前版本目录；PNG 先写临时文件再原子替换。物品材质纹理的 alpha 是游戏着色器遮罩，导出卡图时使用 RGB，英雄与奖杯保留原始透明度，避免卡牌主体在 Android 图片控件中消失。单次只处理一张图片，限制输出尺寸及待写字节，只有托管 PNG 字节交给后台落盘；暂停不消耗加载超时，失败延迟有界重试。该缓存可重新生成，不参与历史 schema、初始化、迁移或修复，也不把当前模板图片当作采集时截图。

`HistoryArtwork` 在启动器后台读取版本指针和 PNG，限制文件大小、解码尺寸、请求队列和内存缓存，拒绝过期绑定与销毁后的回调。缺图时仍显示采集状态和卡牌张数；按用户反馈，启动器阵容页只展示图片，不展示卡名、品质或点击／长按字段弹窗，数据库快照字段继续完整保留。历史页明确说明图片仅供参考；首次升级后需启动游戏让缓存回填，当前账号之外的旧快照需在对应账号进入游戏后补齐。

缓存 PNG 是源材质纹理，其方形像素尺寸不能代表物品的显示比例。启动器以 `HistoryBattleLayout.artworkAspect` 中当前手机版 `CardPreviewItem._cardImage` 区域的实测比例还原原生 UV 映射，再按整排预算统一高度、单行缩放；不从装饰框或方形纹理推断小／中／大型卡图比例。
