# 停靠栏图标来源

`preview-enchant.*`（四角星）与 `preview-upgrade.*`（双折角箭头）为本项目自绘，随 BazaarPlusPlus 的 MIT 许可发布。
其余图标除图鉴外，剪影取自 [game-icons.net](https://game-icons.net)
（仓库 [game-icons/icons](https://github.com/game-icons/icons)，提交 `82d948812bfe3f269ef8f731dcdb07b08160edc4`），
按 [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) 授权使用：

| 文件 | 原图标 | 作者 |
| --- | --- | --- |
| `builds.*` | [Anvil impact](https://game-icons.net/1x1/lorc/anvil-impact.html) | Lorc |
| `history.*` | [Tied scroll](https://game-icons.net/1x1/lorc/tied-scroll.html) | Lorc |
| `hold-preview.*` | [Magnifying glass](https://game-icons.net/1x1/lorc/magnifying-glass.html) | Lorc |
| `preview-none.*` | [Sight disabled](https://game-icons.net/1x1/skoll/sight-disabled.html) | Skoll |

修改：去掉黑色背景，缩放到 84%，改为奶油到金色的竖向渐变填充并加深棕描边，以配合桌面插件的
`collection-panel-icon.png`。`*.svg` 是修改后的完整源文件，`*.png` 由其按 128×128 透明背景导出。
启动器许可页的署名由 `build_launcher.py` 写入 `NOTICE.txt`，增删图标时同步修改。
